Портфолио из трёх концепт-сайтов для вымышленных компаний из Сызрани. Каждый сайт сделан в собственном визуальном языке, как будто их делали три разные студии. В корне лежит витрина со ссылками на все проекты.

Стек: HTML, CSS и чистый JavaScript без сборки. Анимации на GSAP + ScrollTrigger (и Flip в ресторане), плавный скролл на Lenis. Всё подключается с CDN, поэтому сайты открываются на GitHub Pages как есть.

```
/
├── index.html        витрина-портфолио
├── assets/           превью проектов и favicon витрины
├── restaurant/       «Волжский двор»
├── detailing/        «Гараж 163»
└── glamping/         «Сосновый берег»
```

## 01. «Волжский двор», ресторан волжской кухни

**Стиль:** тёмный luxury-editorial, как разворот глянцевого журнала. Графит, слоновая кость, тёплое золото. Шрифты: Cormorant Garamond и Manrope.

**Аудитория:** пары, деловые ужины, гости города.

- Hero в виде многослойной SVG-сцены «вечерняя Волга»: силуэт Спасской башни Сызранского кремля, закат, блики на воде, медленный параллакс по скроллу и за мышью.
- Закреплённая горизонтальная лента фирменных блюд (стерлядь, раки, тройная уха, медовик). На мобильных превращается в свайп-карусель.
- Меню с фильтром по категориям и FLIP-анимацией перестроения.
- Блок шефа, слайдер отзывов, схема проезда в SVG.
- Бронирование столика: дата, время с пометкой «закат», счётчик гостей, повод, маска телефона, валидация и экран «Стол ждёт вас».
- Золотой кастомный курсор, плёночное зерно.

## 02. «Гараж 163», детейлинг-студия

**Стиль:** тёмный tech и неон-брутализм. Чёрный, кислотный лайм, сталь. Шрифты: Unbounded и JetBrains Mono. Видимая сетка и острые углы.

**Аудитория:** владельцы машин 25–45 лет, которым важны результат и прозрачная цена.

- Калькулятор стоимости: класс авто, набор услуг, состояние кузова. Итог выводится живым «чеком» с анимацией суммы и оценкой времени в боксе.
- Слайдер «до/после» с перетаскиванием (мышь, тач и клавиатура через скрытый `range`). Грязь сгенерирована SVG-фильтрами, без второго фото.
- Онлайн-запись в четыре шага: услуги, день и свободные слоты, контакты, проверка. Набор услуг из калькулятора переносится в запись одной кнопкой.
- Анимированные счётчики, бегущая строка, статус «открыто/закрыто» по текущему времени, курсор-прицел с координатами.

## 03. «Сосновый берег», глэмпинг на Волге

**Стиль:** светлый, воздушный, природный. Песок, хвоя, терракота. Шрифты: Nunito и рукописный Caveat. Скругления и рукописные пометки со стрелками.

**Аудитория:** пары и семьи из Сызрани, Самары и Тольятти, которым нужен выезд на выходные.

- Переключатель «утро / день / закат»: меняется палитра всего сайта, по небу иллюстрированного SVG-пейзажа движется солнце, на закате появляются звёзды и загораются окна домиков. Начальное время выбирается по часам посетителя и запоминается.
- Карточки домиков с ценами и переключателем «будни / выходные».
- Календарь доступности для каждого домика: выбор заезда и выезда, проверка занятых ночей, расчёт стоимости с учётом выходных и форма брони.
- Бенто-галерея с лайтбоксом: стрелки, клавиатура, свайп.
- FAQ-аккордеон с плавной анимацией высоты.

## Общее

- Адаптивность проверена на 375, 768 и 1440 px, горизонтального скролла нет.
- `prefers-reduced-motion` отключает GSAP-анимации, плавный скролл и CSS-анимации.
- Без JavaScript и CDN контент остаётся видимым: начальные состояния анимаций задаёт сам скрипт.
- У каждого сайта есть title, description, Open Graph, свой favicon и `theme-color`.
- Фото с Unsplash отдаются в WebP (`fm=webp&auto=format`, `q=70`) с `srcset` на 375/768/1440 px и `sizes` под реальную ширину в вёрстке. Картинки грузятся лениво, у всех указаны размеры и `alt`. Остальная графика нарисована в SVG.
- На фото машин нет логотипов и значков марок.
- Внизу каждого сайта стоит плашка «Концепт-проект. Компания вымышленная».

## Деплой на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `syzran-portfolio`.
2. Отправьте код:
   ```bash
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`. Проекты будут доступны по `/restaurant/`, `/detailing/` и `/glamping/`.

Если форкаете репозиторий под другим логином, замените абсолютный адрес в `og:image` корневого `index.html`.
